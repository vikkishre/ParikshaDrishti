ParikshaDrishti is a secure, browser-based exam proctoring tool built to ensure academic integrity during online assessments. Leveraging advanced JavaScript-based monitoring and front-end security techniques, it actively tracks and restricts user behavior to prevent cheating and misconduct.

Key Features:
Anti Tab-Switching Detection: Tracks and flags when participants switch tabs during the exam.

Right-Click Disabling: Prevents right-click actions to stop copying or viewing source code.

Real-Time Warning System: Issues warnings after suspicious actions (like tab switching).

Attempt Threshold Blocking: Automatically blocks participants after exceeding a set number of violations.

User-Friendly Alerts: Clear, non-intrusive warnings guide users without disrupting honest test-takers.

Built with modern web technologies, ParikshaDrishti ensures a fair and focused testing environment without the need for external monitoring software.
